# Títulos Náuticos: datos públicos

Datos que la app **Títulos Náuticos** descarga para estar al día sin publicar una versión nueva.

- `convocatorias.json`: convocatorias de examen de las titulaciones náuticas de recreo (PNB, PER, Patrón de Yate y Capitán de Yate) por administración: fechas, plazos de matrícula, tasas, requisitos y enlace a la web oficial.

Son datos orientativos recopilados de las publicaciones oficiales de cada administración. **La fecha y las condiciones que valen son las de la web oficial** de cada administración, enlazada en cada entrada (`url_oficial`). Cada fichero indica cuándo se verificó por última vez (`verificado`).

Se publica con GitHub Pages en `https://raca7772.github.io/titulos-nauticos-datos/convocatorias.json`.
